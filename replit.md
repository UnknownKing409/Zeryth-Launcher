# Zeryth Launcher

## Project overview

Zeryth Launcher is an Android Minecraft launcher based on the Zalith Launcher codebase. The authoritative Android app module is `ZalithLauncher/`, and the primary development branch is `Zeryth-Main`.

## User preferences
