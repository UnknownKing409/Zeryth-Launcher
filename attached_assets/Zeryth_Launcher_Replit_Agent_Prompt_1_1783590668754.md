# Objective

The current implementation of the feature requested in **Issue #36** is no longer satisfactory.

Instead of continuing to improve or patch the existing implementation, I want to completely replace it with the implementation from **Zalith Launcher+**, which currently has the best implementation of this feature.

The goal is to make Zeryth Launcher behave the same as Zalith Launcher+ while remaining fully compatible with the latest Zeryth Launcher codebase.

---

# Scope

This task is **only** about the feature described in Issue #36.

Everything outside the scope of that issue should remain unchanged unless modifications are required for compatibility.

---

# Overall Goal

The final implementation should:

- Behave like Zalith Launcher+.
- Look like Zalith Launcher+.
- Use the same workflow as Zalith Launcher+.
- Retain Zeryth Launcher compatibility.
- Preserve all existing launcher functionality unrelated to Issue #36.
