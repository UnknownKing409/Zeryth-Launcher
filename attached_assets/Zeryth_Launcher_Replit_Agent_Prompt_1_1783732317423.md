# Objective

Improve the accessibility of Zeryth Launcher's built-in File Manager by adding a dedicated shortcut on the main screen.

Currently, the File Manager is accessible through other parts of the launcher, but I want users to be able to open it directly from the launcher home screen with a single tap.

This should feel like a natural part of the existing main screen and match the rest of the launcher's design language.
